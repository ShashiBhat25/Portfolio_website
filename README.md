# Shashikumar Bhat - Portfolio

Personal portfolio website for Shashikumar Bhat, a full stack developer, Python developer, and machine learning engineer based in Bengaluru, India.

## Overview

This is a responsive, single-page portfolio built with vanilla HTML, CSS, and JavaScript. It presents professional experience, technical skills, featured projects, education, resume access, and contact links.

## Features

- Responsive layout for desktop and mobile screens
- Smooth scrolling navigation with active section highlighting
- Animated role/typewriter text in the hero section
- Scroll-based reveal animations
- Mobile hamburger navigation
- Interactive project cards with a tilt effect
- Copy-to-clipboard email contact tile
- Links to GitHub, LinkedIn, phone, and downloadable resume
- Animated visual background and orbit-style technology display

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome icons
- Google Fonts: Space Grotesk and Fira Code

## Run Locally

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/ShashiBhat25/Portfolio.git
   cd Portfolio
   ```

2. Start a local web server:

   ```bash
   python -m http.server 8000
   ```

3. Open [http://localhost:8000](http://localhost:8000) in your browser.

You can also open `index.html` directly, although a local server is recommended for the best browser behavior.
